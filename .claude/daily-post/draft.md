# 작성 단계 지침 (daily-post 작성 단계)

<instructions>
## 1. 포스트 초안 작성 (`content/posts/<slug>.md`)
slug는 영문 소문자-하이픈. 작성 전 경로 존재 여부를 확인한다:
- **수동 모드**: 슬러그 충돌 시 사용자에게 확인 후 진행.
- **무인 모드**: 슬러그 뒤 `-2`, `-3` 접미사를 붙여 기존 파일 덮어쓰기를 방지.

### Front Matter 규약
```yaml
---
title: "<변별 키워드 앞배치, 40자 이하>"
date: <현재시각 KST, +09:00>
description: "<핵심 팩트와 결론, 100자 내외 완성문>"
tags: [<topics.yaml에서 2~3개 선택, focus: true 우선>]
draft: false   # §5 검사가 통과일 때. 위반이 남으면 true로 두고 보류한다 (daily-post.md §6)
source_url: "<입력받은 원문 URL>"
faq: # 필수 (2개. 독자 검색형 질문과 본문 기반 답변)
  - q: "<독자가 실제로 검색할 법한 롱테일 자연어 질문>"
    a: "<두세 문장. 본문에 이미 있는 사실로만 답변>"
related_articles: # 3단계 연관 기사가 있을 때만 (0건이면 키 생략)
  - title: "<기사 제목>"
    url: "<기사 URL>"
    source: "<언론사>"
---
```

- **tags 규약**: `.claude/daily-post/topics.yaml` 목록에서만 2~3개 선택. `focus: true` 주제 우선. 새 태그 생성 금지.
- **본문 스타일**: `writing-styles.md`를 100% 준수한다 (마크다운 볼드 `**` 전면 금지, 두괄식, 존댓말체, 선 정의 후 비유).

### 본문 구조 (4단계 H2 필수)
서론 문단 및 핵심 3줄 요약 인용블록(`> 💡 핵심 3줄 요약`)에 이어, 정확히 4개의 H2(`##`)로 섹션을 구성한다:
1. **사건 경위 H2**: 무슨 일이 일어났는지 다루는 주제형/질문형 제목.
2. **배경과 파급 H2**: 왜 중요한지 다루는 주제형/질문형 제목.
3. **생활과 체감 H2**: 청년 일상에 미치는 영향을 다루는 주제형/질문형 제목.
4. **투자 관점 H2**: 자산군 및 업종별 함의를 다루는 주제형/질문형 제목.

- **제목 규율**: `## 무슨 일이 있었나` 등 옛 고정 문구를 쓰지 않는다. 4개 H2 중 최소 3개는 `title`의 핵심 주제어를 담아야 한다 (`headings.py` T4 검사).
- **1차 출처 링크**: 통계/지표 수치를 언급할 경우 1차 출처 6개 공시 호스트(ECOS, FRED, KOSIS, DART, 전국은행연합회 소비자포털, BIS) 중 하나를 링크한다. 없거나 불확실하면 링크를 생략하며 비1차 출처(뉴스 등)를 대신 넣지 않는다.

## 2. 투자 연관성 (분석 노트 4필드 반영)

본문의 4번째 섹션(투자 관점)에서 `analysis.md`가 생성한 4개 필드를 모두 소비한다:
- **건드리는 렌즈**: 경기 흐름 / 돈의 흐름 / 기업 체력 중 건드린 영역을 설명한다.
- **선행 vs 동행**: 지금 당장의 영향인지, 향후를 예고하는 선행 경고인지 타이밍을 명확히 구분한다.
- **확인된 수치**: 분석 노트의 지표가 2개 이상이면 마크다운 표로 정리하고, 1개면 문장으로 서술한다.
- **자산군별 함의**: 아래 3단 서브 구조로 작성하여 독자가 시소 원리를 직관적으로 배우도록 한다:

```markdown
### 🔗 3단계 인과 사슬
[사건 발생] → [전달 경로 메커니즘] → [최종 영향]

### ⚖️ 자산군 & 업종별 시소 (Seesaw)
| 구분 | 상대적 우호 / 방어 자산군·업종 | 상대적 부담 / 주의 자산군·업종 |
|---|---|---|
| 자산군 | <수혜/방어 자산군 (예: 단기 예금, 달러 등)> | <부담 자산군 (예: 장기 채권, 고PER 주식 등)> |
| 업종/산업 | <가격 전가력 우수 업종> | <원가 부담 가중 업종> |

> 💡 투자 공부 포인트: <단순 종목 매매가 아닌, 가격 전가력과 구조적 마진 격차가 벌어지는 원리 1~2문장 해설>
```

- **절대 규칙**: 개별 종목명/티커 작성 금지, 매수/매도 권유 금지, 면책 문구 본문 작성 금지 (Hugo 템플릿이 자동 표시).

## 3. 용어 사전 생성 (필요 시)

본문에 새 핵심 경제 용어가 나오는데 `content/dictionary/_terms.yaml`에 없다면:
1. `content/dictionary/<term-slug>.md`를 생성한다:
   - Front matter: `title`, `date`, `description` (한 문장 정의 필수), `tags: ["용어사전"]`, `draft`는 **같은 회차의 포스트와 같은 값**을 쓴다 (포스트가 보류되면 사전 항목도 보류).
2. 본문 슬롯 구조:
   - **리드**: 엄격한 정의 패턴(`[용어]는 [상위개념]으로서, [원리/역할]을 뜻합니다.`) + 일상 비유 (2~3문단).
   - `## 실생활에서는`: 통장/월급/대출/장바구니 중 1개 경로 집중 해설.
   - `## 투자에서는`: 자산군 영향 작동 원리 서술 + `[이벤트] → [전달 경로] → [자산/업종 영향]` 한 줄 공식.
   - `## 숫자로 보면` (선택): 공시 지표인 경우 최근 값 + 기준일 + 1차 출처 링크.
   - `## 함께 보면 좋은 용어` (선택): 헷갈리기 쉬운 관련 사전 링크.
3. `content/dictionary/_terms.yaml`에 새 항목을 추가한다:
```yaml
<term-slug>:
  title: "<용어>"
  aliases: ["<동의어1>", "<동의어2>"]
```

## 4. 위키 링크 연결
- `_terms.yaml`을 참조하여 본문 내 표제어/동의어에 `[용어](/dictionary/slug/)` 상대 경로 링크를 건다.
- 사전 항목 내에서 자기 자신에게 링크하지 않는다.

## 5. 발행 전 결정론 검사 (Deterministic Gates)

파일 작성 후 아래 검사를 `.venv/bin/python`으로 반드시 실행하여 결과를 확인한다:

```bash
# 5-1. 수치 무결성 검사 (N1~N5) - 재시도 최대 2회
.venv/bin/python .claude/audit/lib/numerics.py --file <파일경로>

# 5-2. 사전 계약 정합성 검사
.venv/bin/python .claude/audit/lib/contracts.py --check terms

# 5-3. 제목 규율 검사 (T1~T4) - 포스트에만 실행, 재시도 최대 2회
.venv/bin/python .claude/audit/lib/headings.py --file <포스트경로>
```

출력의 `total`이 0이면 통과다. 위반이 남으면 가이드에 따라 수정한 뒤 재실행한다.

**이 검사가 유일한 발행 게이트다.** 2026-08-27 무인 운영 전환으로 사람의 승인 단계가
없어졌다 — 예전에는 위반이 남아도 PR 본문에 적어 두면 사람이 텔레그램에서 읽고 반려할
수 있었지만, 이제 그 독자가 없다. 재시도 후에도 위반이 남거나 검사 자체가 돌지 않으면
`draft: true`로 두고 보류한다(`daily-post.md` §6). 위반을 안고 발행하지 않는다.
