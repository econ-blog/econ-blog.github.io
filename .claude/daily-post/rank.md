# 랭킹 단계 지침 (daily-post 랭킹 단계)

후보 기사를 수집·점수 매겨 상위 후보(무인: 1건, 수동: 3건)를 선별한다. 결과는 daily-post.md로 넘긴다(파일로 저장하지 않음).

## 1. 후보 스냅샷 읽기

후보는 GitHub Actions(`daily-collect.yml`의 `candidates` 잡)가 매일 01:30 KST에 미리 수집해
비공개 사이드카 `econ-blog/automation-data`에 올려둔다. **이 단계에서 RSS를 직접
가져오지 않는다** — 루틴 샌드박스는 뉴스 사이트에 도달할 수 없다(`AGENTS.md` 자동화 평면).

```
.venv/bin/python scripts/read_snapshot.py
```

수동 모드에서는 `--allow-local-fetch`를 붙인다. 사이드카에 스냅샷이 없으면 그 자리에서
직접 수집한다(로컬은 egress가 있다).

출력의 `status`로 분기한다. **`ok`가 아니면 후보를 지어내지 않고 중단한다.**

| `status` | 뜻 | 동작 |
|---|---|---|
| `ok` | 본문 확보 후보 있음 | `candidates`로 §2 이하를 진행한다 |
| `no_snapshot` | 오늘자 스냅샷 없음 | 무인은 산출물 없이 종료, 수동은 사용자에게 알리고 멈춘다 |
| `stale` | 스냅샷 날짜 ≠ 오늘 KST | 위와 같다. **어제 뉴스로 글을 쓰지 않는다** |
| `no_usable` | 후보는 있으나 본문이 전부 미달 | 위와 같다 |
| `sidecar_unreachable` | 사이드카 접근 자체 실패 | 위와 같다. 단 **"뉴스 없음"과 구분해서** 보고한다 |

`candidates`의 각 항목은 `title`·`url`·`published_at`(KST, `+09:00`)·`source`·`feed`·
`body_text`·`body_chars`를 갖는다. `body_text`가 곧 daily-post.md §2의 원문이다 —
§2에서 다시 가져오지 않는다.

`feeds_used`를 출력에 기록한다. `feed_errors`가 비어 있지 않으면 그것도 적는다.

풀은 이미 발행시각 최신순 30건 이하로 잘려 있고 URL 중복이 제거되어 있다. 24시간 창도
수집 시점(01:47 KST) 기준으로 적용되어 있다.

## 2. 중복 판정 (점수 체계 4번·5번 항목에서만 반영)

과거 포스트 대조:
- `content/posts/`를 스캔하되 `_index.md`, `welcome.md`는 제외한다.
- 후보 URL이 기존 포스트의 `source_url` 또는 `related_articles[].url`과 **정확히 일치**하면 탈락.
- 제목 유사도·태그 겹침으로 근접도를 판단해 점수 체계 4번 항목에서 감점. **후속 보도 예외**: 새 수치·정책 결정 등 새로운 국면을 다루면 감점하지 않는다.
- 혼합 피드 간 중복: 제목 유사도로 같은 사건 기사끼리 묶고, 가장 정보가 많은/원본에 가까운 것 하나만 남긴다.

용어사전 대조:
- `content/dictionary/_terms.yaml`을 읽어 `title`뿐 아니라 **`aliases` 전체**로 매칭한다.
- 매칭 결과는 점수 체계 5번 항목에서만 반영한다. "최근 정리한 용어" 같은 시간 한정어는 쓰지 않는다 — `_terms.yaml`에 타임스탬프가 없어 무의미하다.

## 3. 점수 체계 (15점 만점, 5개 기준 × 0~3점)

각 후보에 아래 5개 기준을 0~3점(0=해당 없음, 3=강함)으로 매긴다:

1. **일반인 관심도** — 생활 밀접도.
2. **경제적 중요도** — 파급력.
3. **투자 도움도** — 경기 흐름(성장 방향), 돈의 흐름/유동성(금리·신용여건), 기업 체력(실적·밸류에이션) 중 하나라도 건드리는 기사. 거시 맥락을 설명할 수 있는지에 대한 점수이지, 방향성 단정의 근거가 아니다.
4. **과거 발행글과의 비중복성** — §2의 후속 보도 예외를 반영한 감점 결과를 이 항목에만 매긴다(다른 항목에서 다시 감점하지 않는다).
5. **용어사전 연관성** — §2의 alias 매칭 결과를 이 항목에만 매긴다.

**조회수 신호는 존재하지 않는다**(GA4 미연동). 출력에 이 문장을 명시한다.

동점 처리(순서대로): ① 투자 도움도 높은 쪽 → ② 발행시각 최신 쪽 → ③ 한경 피드 우선.

### 집중 주제 가점

`.claude/daily-post/topics.yaml`을 Read해 `focus: true`가 붙은 주제(2026-08-10 기준
금리·물가·부동산·반도체)를 얻는다. 후보에 붙일 태그가 그중 **하나라도** 포함하면 총점에 +1.
둘 이상 포함해도 +1이며 중복 가산하지 않는다.

붙일 태그는 `draft.md` §1의 태그 규칙(목록 안에서만, `aliases`로 상위 태그 매핑)과 같은
방식으로 판단한다 — 여기서 다른 어휘를 쓰지 않는다.

### 감사 리포트 반영 (있으면만)
`.claude/audit/topic-report.md`가 존재하면 읽고, 형식은 `AGENTS.md`의 「`topic-report.md` 형식 계약」 절을 따른다. 후보 총점에 −2~+3 범위 조정을 더한다(15점 만점·8점 임계값은 고정). 90일 이상 경과 파일은 +1까지만 적용, 감점 없음. 없으면 건너뛴다.

### 총점 합산 순서

순서를 바꾸면 clamp 지점이 달라져 같은 후보가 다른 점수를 받는다. 아래 순서로만 계산한다.

1. 5개 기준 합계 (0~15)
2. `topic-report.md` 조정치 (−2~+3, 파일이 없으면 0)
3. 집중 주제 가점 (0 또는 +1)
4. 결과를 **0~15로 clamp**
5. 8점 임계값 판정

**15점 만점과 8점 임계값은 고정이다.** 가점도 조정치도 그 둘을 바꾸지 않는다 — 만점을 넘길
수 없고 임계값이 내려가지도 않는다.

## 4. 임계값 판정

- **무인 모드**: 1위 점수 **8점 미만**이면 종료한다. 8점은 초기값이며 실행 로그의 점수 분포로 별도 보정한다.
- **수동 모드**: 상위 3건을 제시. 24시간 창에서 3건 미달 시 48시간으로 재수집. 3건 미달 시 있는 만큼만 제시. 전부 8점 미만이면 "오늘 추천 후보 없음"을 보고하고 멈춘다 — 점수를 채우려고 약한 후보를 억지로 끼워 넣지 않는다.

## 5. 다음 단계로 넘기는 것
- **무인 모드**: 1위 후보(제목·URL·발행시각·점수)만 daily-post.md의 원문 fetch 단계로 넘긴다.
- **수동 모드**: 표로 제시한 3건 중 사용자가 고른 1건을 다음 단계로 넘긴다. 애매하면 AskUserQuestion으로 확인(수동 모드만).
